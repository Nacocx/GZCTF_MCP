# 官方 API 对照核查规格

日期：2026-11-17。

## 目标与交付

以官方 Scalar 页面实际引用的 `https://gzctf.gzti.me/openapi.json` 为基准，对当前 MCP 的路由、方法、请求模型、鉴权、响应解析及组合工作流做核查。交付审查报告、覆盖记录和少量可复现的本地疑点验证。

## 方法

1. 保存 OpenAPI 摘要与操作清单，核对当前注册工具的覆盖范围。
2. 检查字段、枚举、必填项、multipart 和二进制处理；文档无法解释的行为对照官方源码，并记录源码版本。
3. 使用现有 conda 环境和 MockTransport 验证高价值疑点；不执行大规模测试。
4. 报告区分确定缺陷、兼容性风险和可选能力扩展，给出位置、触发条件、影响与修复方向。

## 范围

本轮为审查，运行代码保持原状。仅访问公开官方资料，不加载部署凭据或向业务站点写入数据。新增文档位于 `docs/`，并更新 `docs/CHANGELOG.md`。

## 完成条件

形成当前工具与官方 API 的覆盖清单；重要结论有代码或本地复现依据；清楚记录未执行的真实服务验证。
