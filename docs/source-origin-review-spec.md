# 源码来源与许可证核对规格

日期：2026-10-23；核对版本：0.3.1。

目标：核对独立 MCP 实现与本地参考 GZCTF 的来源关系，为主项目选许可证提供证据，不直接替用户选许可证或发布。

步骤：固定双方文件清单与 SHA256、上游 commit 和许可证边界；逐文件审阅适配器、脚本、测试和部署文件；对非受限上游源码做同文件/连续文本/字符串匹配，并人工判断协议常量与可保护实现的区别；复核 wheel/sdist 的实际分发内容和 wsrx 许可副本；记录加密等重点实现的来源与残余不确定性。

限制：相似度结果不是著作权结论；跨语言改编不能靠零文本匹配排除。GZCTF 受限组件只核对许可清单与依赖/打包边界，不分析其实现。保持参考源码、环境凭据和主项目许可证不变；仅增加核对脚本/报告和 changelog，不运行平台请求或提交 Flag。
