# 本地 Docker MCP 实测规格

## 目标

在独立 Compose 项目 `gzctf-mcp-verify-20261117` 中启动 GZCTF/PostgreSQL，通过真实 MCP stdio 验证工具可用性和 2026-11-17 修复。

## 环境

复用仓库已固定摘要的官方 GZCTF 镜像及加密测试覆盖配置，监听 `127.0.0.1:18082`；数据库和文件卷按新项目名隔离。凭据使用忽略目录 `.local-test/compose.env`，不输出到日志或验收记录。保留用户现有 `.env` 和原测试项目。

## 验证

1. 等待容器健康、公开配置可读，记录实际版本和镜像摘要。
2. 真实 MCP 初始化、工具发现、管理员/选手加密登录。
3. 上题、附件引用计数与删除后下载、恢复、分组审核、比赛并发修改、导入导出及清理。
4. 本地专用比赛中验证 Flag 提交及异步判题、题目容器启动/连通/停止。
5. 如使用故障注入，仅对本地实例的 HTTP 转发丢弃指定响应，明确区别于自然网络故障和长期 Cookie 续期。

## 收尾

记录实际通过和失败项目，修复发现的兼容问题并定向复验；清理本次创建的测试比赛/队伍/题目容器，保留平台实例运行供用户继续检查。说明访问地址、凭据文件与停止命令；更新 changelog。
